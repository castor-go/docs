Static Assets

Serving static files.

Mount a directory under a URL path with StaticAssets, then add browser cache headers and ETag revalidation when you need them.

  • 2 examples
  • Go 1.27+
  • net/http
1

Serve a directory

Call StaticAssets with a URL pattern and a directory. This example serves ./public under /assets/.

main.go 
package main

import (
	"log"
	"net/http"

	"github.com/castor-go/castor"
)

func main() {
	server := castor.Server().
		StaticAssets("/assets/**", "./public").
		Routes(
			castor.Get("/", func(w http.ResponseWriter, r *http.Request) {
				castor.Json(w, map[string]string{"message": "Hello"})
			}),
		)

	if err := server.Start(); err != nil {
		log.Fatal(err)
	}
}
/assets/css/site.css reads ./public/css/site.css

How patterns map to files

Static asset pattern examples
Pattern Request File
/assets/** /assets/css/site.css ./public/css/site.css
/static/* /static/logo.svg ./public/logo.svg
/ /favicon.ico ./public/favicon.ico

A trailing * or ** is stripped from the pattern. Files are served with http.FileServer semantics, and only GET routes are registered; HEAD is handled by ServeMux automatically. The directory is resolved relative to the server process working directory.

2

Add caching and ETags

Pass a StaticConfig to set a browser cache lifetime and enable ETag revalidation.

main.go 
package main

import (
	"log"
	"net/http"
	"time"

	"github.com/castor-go/castor"
)

func main() {
	server := castor.Server().
		StaticAssets("/assets/**", "./public", castor.StaticConfig{
			CacheMaxAge: 24 * time.Hour,
			ETag:        true,
		}).
		Routes(
			castor.Get("/", func(res http.ResponseWriter, req *http.Request) {
				castor.Json(res, map[string]string{"message": "Hello"})
			}),
		)

	if err := server.Start(); err != nil {
		log.Fatal(err)
	}
}
Responses include Cache-Control and ETag

StaticConfig options

StaticConfig fields
Field Default Effect
CacheMaxAge 0 When positive, sets Cache-Control: public, max-age=<seconds>. Zero omits the header.
ETag false Generates an ETag from the file modification time and size. A matching If-None-Match returns 304 Not Modified.

StaticAssets uses only the first StaticConfig when several are passed. ETags are based on file metadata, so replacing a file with identical size and modification time can reuse the same ETag.

Reference the files

Once mounted, the files are ordinary URLs. Link them from your HTML or clients:

index.html 
<link rel="stylesheet" href="/assets/css/site.css">
<script src="/assets/js/app.js" defer></script>
<img src="/assets/img/logo.svg" alt="Logo">

Keep the public tree public.

Everything inside the configured directory can be requested through the mounted URL. Do not place secrets, source files, or private uploads in a directory passed to StaticAssets.

Core API Middlewares

Middlewares

Middleware in plain functions.

Castor middleware is a function that wraps an http.Handler. Write one with the standard library, apply it globally or to a route, and keep the same composable API as the built-in middleware.

  • Plain Go
  • Go 1.27+
  • Standard library
1

Create a middleware

A middleware accepts the next handler and returns a new handler. Call next.ServeHTTP to continue the chain. This example logs how long each request takes:

main.go 
package main

import (
	"log"
	"net/http"
	"time"

	"github.com/castor-go/castor"
)

func requestTimer(next http.Handler) http.Handler {
	return http.HandlerFunc(func(res http.ResponseWriter, req *http.Request) {
		start := time.Now()
		next.ServeHTTP(res, req)
		log.Printf("%s %s took %s", req.Method, req.URL.Path, time.Since(start))
	})
}

func main() {
	server := castor.Server().
		Middlewares(requestTimer).
		Routes(
			castor.Get("/", func(res http.ResponseWriter, req *http.Request) {
				castor.Json(res, map[string]string{"message": "Hello"})
			}),
		)

	if err := server.Start(); err != nil {
		log.Fatal(err)
	}
}

Any func(http.Handler) http.Handler works; castor.Middleware is an alias for that signature.

2

Integrate the middleware

Apply custom middleware globally, to one route, or to a route group. The first middleware in a list is the outermost and runs first.

main.go 
// Global: runs for every request, including unmatched routes.
server := castor.Server().Middlewares(requestTimer)

// Route: runs only when this route matches.
server.Routes(
	castor.Get("/admin", adminHandler).Middlewares(requireAdmin),
)

// Group: runs for every route in the group.
api := castor.Group("/api",
	castor.Get("/users", listUsers),
).Middlewares(requireAPIKey)
server.Groups(api)

Global middleware wraps the router, so it also sees requests that do not match a route. Route and group middleware run only after the router has selected a route. With multiple middleware, the first listed is outermost.

Built-in middlewares

These middleware ship with Castor in github.com/castor-go/castor/middleware.

Built-in Castor middlewares
Middleware Description
AllowContentEncoding Rejects request bodies whose Content-Encoding is not allowed.
AllowContentType Rejects request bodies whose media type is not allowed.
BasicAuth Protects handlers with HTTP Basic authentication.
CORS Handles CORS preflight requests and response headers.
CORSAllowAll Permissive CORS preset for all origins, methods, and headers.
CleanPath Cleans duplicate slashes and dot segments before routing.
ClientIPFromHeader Reads the client IP from a trusted proxy header.
ClientIPFromRemoteAddr Stores the client IP from RemoteAddr.
ClientIPFromXFF Resolves the client IP from X-Forwarded-For using trusted prefixes.
ClientIPFromXFFTrustedProxies Resolves the client IP by counting trusted proxies.
Compress Compresses responses with gzip or deflate based on Accept-Encoding.
ContentCharset Rejects request bodies whose charset is not allowed.
Deprecation Adds RFC 9745 Deprecation and Link headers.
GetHead No-op for ServeMux; HEAD is already routed to GET handlers.
Heartbeat Answers a GET or HEAD health endpoint without invoking the chain.
Maybe Applies another middleware only when a condition matches.
New Turns any handler into middleware that always serves it.
NoCache Adds response headers that prevent caching.
PageRoute Serves a handler for an exact, case-insensitive GET path.
PathRewrite Rewrites the first occurrence of a path prefix before routing.
Recoverer Recovers panics, logs them, and returns a 500 response.
RedirectSlashes Redirects trailing-slash paths to their canonical form.
RequestID Adds or reuses a request ID and stores it in the context.
RequestSize Limits the number of request body bytes a handler can read.
RouteHeaders Routes to middleware based on request header values.
SecureHeaders Adds Hono-style security headers with defaults.
SecureHeadersWithOpts Security headers with custom CSP, permissions, and header options.
SetHeader Sets a response header before calling the next handler.
StripSlashes Removes one trailing slash before routing.
Sunset Adds RFC 8594 Sunset and Link headers.
SuppressNotFound / SupressNotFound Serves the mux's 404 or 405 response before later middleware.
Throttle Limits the number of in-flight requests.
ThrottleBacklog Adds a finite wait queue to the in-flight request limit.
ThrottleWithOpts Configures throttling, backlog, status codes, and Retry-After.
Timeout Cancels the request context after a deadline and returns 504 when needed.
URLFormat Extracts a trailing URL extension and stores it in the context.
WithValue Stores a value in the request context for later handlers.

Compose what you need.

Start with one small middleware, apply it where it belongs, and keep the standard library handler contract.

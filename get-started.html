Get Started

Build a simple web API.

Create a small JSON API with Castor in one Go file. You will add routes, read a path parameter, accept JSON, and start a server built entirely on the standard library.

  • ~10 min
  • Go 1.27+
  • Zero dependencies
1

Set up the module

Create a new directory, initialize a Go module, and add Castor.

terminal 
mkdir castor-api
cd castor-api
go mod init castor-api
go get github.com/castor-go/castor
2

Write the API

Create main.go. The server exposes a status endpoint, a route with a path parameter, and an endpoint that accepts JSON.

main.go 
package main

import (
	"log"
	"net/http"

	"github.com/castor-go/castor"
	"github.com/castor-go/castor/middleware"
)

func main() {
	api := castor.Server().
		Middlewares(
		    middleware.Recoverer,
			middleware.Heartbeat("/health")
		).
		Routes(
			castor.Get("/hello/{name}", func(res http.ResponseWriter, req *http.Request) {
				name := castor.GetPathParam(req, "name")
				castor.Json(res, map[string]string{
					"message": "Hello, " + name + "!",
				})
			}),
			castor.Post("/echo", func(res http.ResponseWriter, req *http.Request) {
				var body map[string]any
				if err := castor.ReadJson(req, &body); err != nil {
					castor.Json(w, map[string]string{"error": err.Error()}, http.StatusBadRequest)
					return
				}
				castor.Json(res, body, http.StatusCreated)
			}),
		)

	if err := api.Start(); err != nil {
		log.Fatal(err)
	}
}

The Recoverer middleware turns panics into 500 responses instead of crashing the server.

3

Run the server

Start the app from the project directory.

terminal 
go run main.go
Listening on http://0.0.0.0:3000

Press Ctrl+C to stop it. Castor handles the interrupt and shuts down gracefully.

4

Call the API

The API has three routes:

GET /health

Returns the API status.

GET /hello/{name}

Reads a path parameter.

POST /echo

Parses JSON and returns it.

terminal 
curl http://localhost:3000/health
# {"status":"ok"}

curl http://localhost:3000/hello/Ada
# {"message":"Hello, Ada!"}

curl -X POST http://localhost:3000/echo \
  -H "Content-Type: application/json" \
  -d '{"task":"ship it"}'
# {"task":"ship it"}

You have a running web API.
